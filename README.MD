## 🚀 Global Sales & Logistics Report (Power BI)

**Objective:** Engineered an end-to-end operational Business Intelligence solution analyzing global corporate retail datasets, driving data-backed decisions for international sales volumes, supply chain logistics, and region-specific profit optimization.

### 🖼️ Dashboard Preview
![Dashboard Overview](screenshots/Global_Sales_&_Logistics_Report%20(1).jpg)

### 🧩 Technical Features & Engineering Architecture
* **Advanced Data Ingestion & Transformation:** Processed multi-source operational metrics, executing strict data type casting, null-value structural handling, and field normalization across distinct regional distribution records.
* **Relational Data Modeling:** Architected a high-performance Star Schema framework, mapping multi-dimensional corporate entities into integrated sales and logistics fact tracking tables.
* **AI-Driven Supply Chain Telemetry:** Implemented Power BI **Decomposition Tree** AI visuals to dynamically profile operational return rates, break down multi-market shipping expenses, and run root-cause analysis on delivery mode failures.
* **Time-Intelligence & Commercial Core Metrics:** Programmed optimized DAX measure structures to calculate absolute profit margins, return on sales (ROS), volume velocities, and synchronized Year-over-Year (YoY) corporate performance metrics.
* **App-Like Executive Interface:** Developed a custom vertical sidebar application-style navigation layout to allow stakeholders seamless context switching between granular Sales, Customer cohorts, and Shipping views.

### 📂 File Structure
* `Global_Sales_&_Logistics_Report.pbix`: High-performance core data model and interactive multi-view analytical layout.
